# 实施计划

## 目标与验收

为当前分类提供桌面端右侧悬浮网站速览，并在顶部提供直接跳转 Google 的搜索框；网站图标在刷新和分类切换时只显示最终正确状态。

## 关键决定

- 不增加第二份网站数据；`renderCards()` 生成一次 `orderedLinks`，同时驱动卡片和速览。
- 1080px 是速览显示断点；桌面通过第三个网格列预留空间，窄屏直接隐藏。
- 使用原生按钮和现有 `scrollIntoView()` 定位，不增加依赖或新的滚动状态。
- 运行时比较卡片与速览的 `data-*` 顺序，出现偏差立即报错。
- Google 搜索使用原生 `<form method="get" target="_blank" rel="noopener">` 和 `q` 参数；不新增脚本，现有站内搜索通过明确表单 `id` 保持隔离。
- 现有 `google.cn.png` 是 Chrome 图标，因此使用内联四色 G SVG，不新增资源文件或外部图片请求。
- 图标图片默认可见、备用标识默认隐藏；只在原生 `error` 事件时切换备用状态，不增加预加载器或额外状态。
